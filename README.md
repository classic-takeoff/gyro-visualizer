# 🧭 陀螺仪姿态可视化 Gyro Visualizer

一个**零依赖、纯静态**的网页：读取手机浏览器陀螺仪（DeviceOrientation）数据，
用 **CSS 3D** 实时渲染设备的立体姿态，并显示偏转角度（α 方位 / β 俯仰 / γ 横滚），
附带实时曲线、姿态仪表与罗盘。桌面电脑无陀螺仪时自动进入**模拟模式**（滑杆/自动摇摆）。

## 特性

- 📱 手机端：真实传感器驱动 3D 模型，支持 iOS 13+ 授权流程与 Android 自动接入
- 🖥️ 桌面端：α/β/γ 滑杆模拟 + 自动演示摇摆，方便开发调试与演示
- 🎯 3D 手机模型：CSS 3D 无任何第三方库，可拖拽旋转视角 / 滚轮缩放 / 双击复位
- 📊 角度大字读数 + 姿态仪表 + 最近 30 秒实时曲线（Canvas）
- 🧭 罗盘方位浮层；事件频率、绝对方位(罗盘)/相对航向标识
- 🔒 隐私：数据仅在本地浏览器计算，**绝不上传**

## 快速开始

1. **本机体验（无需服务器）**：双击打开 `index.html` → 桌面自动进入模拟模式，拖动滑杆即可看到手机模型转动。
2. **手机真机**：浏览器只在 **HTTPS / localhost**（安全上下文）下提供方向传感器，因此需部署到任意静态托管：
   - GitHub Pages / Vercel / Cloudflare Pages / Netlify（把本目录内容推上去即可），或自建 nginx/nginx https；
   - 手机浏览器打开后点右上角 **「传感器」**，iOS 在弹窗选“允许”。
3. 本机临时 HTTP 预览：`python -m http.server 8000`（本机 `http://localhost:8000` 属于安全上下文；手机经局域网 IP 访问则**不是**安全上下文，传感器不可用，需 HTTPS 或浏览器“不安全来源视为安全”实验开关）。


## 角度与坐标约定（遵循 W3C Device Orientation Events）

- **地球坐标系**：X 向东、Y 指向真北、Z 垂直向上（ENU）。
- **设备坐标系**：x 屏幕向右、y 指向屏幕顶部、z 垂直屏幕向外；参考姿态为设备平放桌面、屏朝上、顶朝北。
- **欧拉角（右手系，内在旋转序）**：
  1. 绕 Z 轴转 `α`（方位/偏航，0–360°，平放时 0°=北、90°=西、180°=南、270°=东）；
  2. 绕新 x 轴转 `β`（俯仰/前后倾，0–180°，0=平放、90=竖立、180=翻转屏朝下）；
  3. 绕新 y 轴转 `γ`（横滚/左右倾，−90–90°）。

模型旋转矩阵由 `js/orient.js` 按 **Rodrigues 公式迭代基向量**实现，
并用独立实现（四元数复现）交叉验证：`node tests/orient.test.mjs`（2000 组随机 + 解析姿态点断言，全部通过）。

> 已知平台差异：个别机型/浏览器对基准与符号有实现差异（尤其横竖屏锁定场景），属厂商问题而非本页数学错误。

## 技术说明

- 为什么用 CSS 3D 而不是 Three.js：本仓库开发环境无法访问外网（CDN/npm 均不可达），故做成**完全离线、零依赖**，
  双击即可打开。如日后需要更复杂渲染，把 `#phone` 及其面片换成 Three.js Mesh 即可，姿态矩阵数学（orient.js）可直接复用。
- 交互：`#scene` 指针拖拽旋转视角（`CAM.pitch/yaw/zoom`），滚轮缩放，单击（未拖拽）复位视角。
- 曲线：环形采样 30 秒 / ~30 Hz，按 DPR 高清绘制，点击图例右侧 ⏸ 可暂停。

## 环境要求

现代浏览器即可；手机传感器需安全上下文 + 用户授权。无任何构建步骤、无第三方依赖。
