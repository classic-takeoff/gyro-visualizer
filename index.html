角度含义（遵循 W3C Device Orientation Events 规范）

α 方位角/偏航 (0–360°)：绕“屏幕法线”的转角；设备平放时 ≈ 顶部指向，0°=北、90°=西、180°=南、270°=东。
β 俯仰/前后倾 (0–180°)：绕左右方向轴的倾角；0°=平放(屏朝上)、90°=竖立、180°=翻转(屏朝下)。
γ 横滚/左右倾 (−90–90°)：绕顶部方向轴的倾角；0°=端正、正=右倾、负=左倾。

参考初始姿态：设备平放桌面、屏朝上、顶朝北 → (α,β,γ)=(0,0,0)。设备系：x 屏幕向右、y 指向顶部、z 垂直屏幕向外。旋转顺序为 α(绕 Z)→β(绕新 X)→γ(绕新 Y)。

手机真机使用

  1. 浏览器只在 HTTPS 或 localhost（“安全上下文”）提供方向传感器：把本文件夹部署到任意静态托管（GitHub Pages / Vercel / Cloudflare Pages / nginx 等），用手机打开。
  2. 点击右上角 「传感器」；iOS 会弹窗授权，Android 一般直接可用。
  3. 若长时间无数据：检查是否 HTTPS、是否给了权限、是否在浏览器内而非第三方 App 内置页。
  4. 状态 方向:绝对 = 拿到罗盘绝对方位角；相对 = 仅相对航向。

电脑（无陀螺仪）怎么体验

自动进入「模拟模式」：用左侧 模拟控制 的 α/β/γ 滑杆，或点击 演示摇摆 自动摆动，3D 模型同步转动，也可按住 3D 画面拖动换视角。点击右上角「模拟模式 / 传感器」随时切换。

已知平台差异

个别机型/浏览器对 Euler 角基准与符号存在实现差异（尤其横竖屏与“方向锁定”时），这是厂商实现问题。本页数学严格按 W3C 规范实现，并附 Node 交叉验证测试（tests/orient.test.mjs）。页面不请求摄像头/麦克风/定位，数据只在本地浏览器计算，绝不上传。

技术栈

零依赖纯静态页面：CSS 3D 渲染设备模型、Canvas 绘制曲线；姿态矩阵由 js/orient.js（Rodrigues 迭代按内在旋转序）计算。
