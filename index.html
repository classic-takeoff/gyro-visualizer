怎么用

  1. 用手机(建议竖屏)打开本页(需 HTTPS)，点右上角「传感器」；iOS 会弹窗，点“允许”。
  2. 授权后按平时拿手机的样子竖着拿好，1 秒内页面自动以此姿势作为“起始基准”：此时模型显示为竖立、屏幕正对观察者，α/β/γ 归到 90/0 等基准值。
  3. 之后转动/倾斜手机，模型与角度随之相对变化：平放桌面→模型平放(β→0)；翻转→模型翻面(β→180)；左右倾→γ 正负。
  4. 若中途想换基准：在 3D 画面上快速双击即可用你当前拿法重新对准。单击画面 = 复位视角；按住拖动 = 转视角；滚轮/双指缩放。

角度为什么是“相对”的

不同手机/浏览器的传感器坐标基准差异很大（不少机型硬件方向为横屏）。为让“你怎么拿，模型就怎么显示”，页面把你授权那一刻的拿姿自动设为基准，此后 α/β/γ 均为相对该基准的角度，含义直观且跨机型一致：β 90=竖立正对、0=平放屏朝上、180=翻转屏朝下；γ 左/右倾；α 绕屏幕法线转动。

读数经过平滑滤波，避免手持微抖造成跳动；若嫌太“钝”，模型永远跟手但不剧烈抖。

模型怎么看

深色渐变=屏幕正面，浅色=机身背面；模型上发光射线为设备坐标轴：红 x(向右)、绿 y(顶部)、蓝 z(屏幕法线)。

没有传感器 / 想先看效果

电脑浏览器自动进入模拟模式：用 α/β/γ 滑杆或“演示摇摆”驱动同一套渲染。

隐私与实现

方向数据仅在本机浏览器计算，绝不上传。零依赖：CSS 3D 渲染、Canvas 曲线、姿态矩阵在 js/orient.js（附 Node 交叉验证 node tests/orient.test.mjs）。
