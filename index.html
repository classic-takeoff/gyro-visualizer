怎么用

  1. 手机(建议竖屏)打开本页(需 HTTPS)，点右上角「传感器」；iOS 弹窗选“允许”。
  2. 授权后按平时拿手机的样子竖握拿稳约 1 秒，页面自动以此姿势为“起始基准”，模型显示为竖立、正对观察者。
  3. 之后模型与 α/β/γ 均为相对该基准的变化：平放→β≈0、翻转→β≈180、左/右倾→γ、转身→α。
  4. 双击 3D 画面 = 用当前拿法重新对准；单击 = 复位视角；拖动 = 转视角；滚轮/双指 = 缩放。

实现

模型用 Canvas 2D 投影渲染（无 DOM 3D 图层、无每帧透明度重绘），姿态矩阵驱动顶点投影，手机为圆角棱柱：正面深色屏幕、背面浅色、侧边区分明暗；红/绿/蓝短射线标出设备 x/y/z 轴。

角度 = 相对起始拿姿，经小幅平滑。方向数据仅在本机计算、绝不上传。
