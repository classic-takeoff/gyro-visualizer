角度含义（遵循 W3C Device Orientation Events 规范）

α 方位角/偏航 (0–360°)：绕“屏幕法线”的转角；设备平放时 ≈ 顶部指向，0°=北、90°=西、180°=南、270°=东。
β 俯仰/前后倾 (0–180°)：绕左右方向轴的倾角；0°=平放(屏朝上)、90°=竖立、180°=翻转(屏朝下)。
γ 横滚/左右倾 (−90–90°)：绕顶部方向轴的倾角；0°=端正、正=右倾、负=左倾。

模型上的彩色射线 = 设备坐标轴：红 x(向右)、绿 y(顶部)、蓝 z(屏幕法线/朝向)。浅色面为手机背面，深色屏幕为正面。

第一次打开：模型方向不对怎么办？(很重要)

不同手机/浏览器对坐标系基准的实现在在差异（部分机型传感器“自然方向”是横屏等），若你竖握手机正对屏幕时模型却是横向/躺倒的，请：

  1. 保持竖屏（建议锁定竖排），把手机竖着正对自己拿好；
  2. 点场景下方的 🎯 对准我 —— 模型会立刻以“当前姿态=竖立、屏幕正对观察者”为基准重新显示；
  3. 若仍差 90°/180°，用 ↺90° / ↻90° 微调；不想要了点 重置。

校准只影响 3D 模型朝向，不影响右侧 α/β/γ 原始读数。读数是按 W3C 规范的解释；个别机型读数本身的符号/基准也可能不同（多数教程里提到的横竖屏差异即属此类）。

抖动太灵敏？

「平滑」滑杆调节滤波强度：越大越稳（滞后略明显），越小越跟手（抖动多）。默认 45，可在 0–100 间按喜好调。曲线显示的是平滑后数值。

手机真机使用

  1. 浏览器只在 HTTPS 或 localhost 下提供方向传感器：把页面部署到任意静态托管（本页已在 GitHub Pages）用手机打开。
  2. 点右上角 「传感器」；iOS 弹窗点允许。若长时间无数据：检查 HTTPS、权限、是否浏览器内置页。
  3. 状态 方向:绝对 = 罗盘绝对方位；相对 = 仅相对航向（α 会漂）。

电脑（无陀螺仪）体验

自动进入「模拟模式」：用左侧 α/β/γ 滑杆或 演示摇摆，3D 模型同步转动；按住画面拖动换视角。

技术说明

零依赖纯静态：CSS 3D 渲染、Canvas 曲线。姿态矩阵在 js/orient.js（W3C 约定 + Rodrigues 迭代），校准=乘固定旋转矩阵 X；数学配有 Node 交叉验证（node tests/orient.test.mjs）。方向数据仅在本机浏览器计算，绝不上传。
